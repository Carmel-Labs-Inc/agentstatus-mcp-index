# Flourish Heritage Flour Mill

The server at https://flourish-heritage-flour-mill.mcp.agentstatus.dev/ is a public MCP. It does not ask for a key.

1. Read the tool list from that server.
2. Call a tool that the list names, with that tool's arguments.
3. Do not invent a tool name.
